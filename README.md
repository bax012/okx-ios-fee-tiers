## Maker 和 Taker 有什么区别

理解 Maker 和 Taker，有助于判断自己实际支付的手续费。

- **Maker**：订单没有立即和现有订单成交，而是进入订单簿等待成交。
- **Taker**：订单立即吃掉订单簿中的已有流动性。

一般来说，Taker 费率会高于 Maker。以 Regular 用户公开标准费率为例，Maker 为 0.2000%，Taker 为 0.3500%。但实际成交时，订单可能分多次成交，也可能同时出现不同成交方式，因此最终费用应以订单历史中的明细为准。

如果使用快捷买卖或 Convert，页面可能直接给出一个包含价格差异的报价，不一定单独显示传统订单簿里的 Maker/Taker 费用。官方帮助页面指出，快捷买卖和 Convert 的成本可能体现在报价价差中；看到“0%”也不代表最终成交金额一定完全等于预估金额。
